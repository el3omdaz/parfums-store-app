# Parfums Store v2

متجر عطور متكامل يعمل من خدمة واحدة على **Railway**، مع قاعدة بيانات وصور على **Supabase**، وملفات محفوظة على **GitHub**.

## ما تم إنجازه

- واجهة متجر عربية متجاوبة للجوال والكمبيوتر.
- أقسام: فرنسي، عربي، نيش، حصري، نسائي، رجالي، ويونيسكس.
- البحث، المفضلة، تفاصيل المنتج، السلة والكميات.
- طلبات زوار بدون تسجيل دخول.
- تسجيل اختياري برمز واتساب أو SMS عبر Twilio.
- إتمام الطلب بالعناوين وطرق الدفع المتاحة.
- احتساب السعر والمخزون داخل الخادم وقاعدة البيانات لمنع التلاعب.
- قسم «اطلب عطرك من الماركات العالمية» مرتبط بلوحة الإدارة.
- لوحة إدارة آمنة بجلسة JWT، وليست بكلمة المرور نفسها.
- إدارة المنتجات والأسعار والمخزون والصور والطلبات والعملاء والماركات.
- إعداد الدولة والعملة ومفتاح الهاتف ورسوم التوصيل من لوحة الإدارة.
- محذوفات واستعادة المنتجات ونسخة احتياطية بصيغة JSON.

## التشغيل والنشر بدون Terminal

استخدم ملف [SETUP_NO_TERMINAL.md](SETUP_NO_TERMINAL.md). جميع الخطوات تتم من متصفح GitHub وSupabase وRailway فقط.

## الروابط بعد النشر

- المتجر: رابط Railway الرئيسي.
- لوحة الإدارة: أضف `/admin` في نهاية رابط Railway.
- فحص الخادم: أضف `/health` في نهاية الرابط.

## متغيرات Railway المطلوبة

| المتغير | الاستخدام |
|---|---|
| `SUPABASE_URL` | رابط مشروع Supabase |
| `SUPABASE_SECRET_KEY` | المفتاح السري الجديد من Supabase. يمكن استخدام `SUPABASE_SERVICE_ROLE_KEY` للمشاريع القديمة |
| `JWT_SECRET` | مفتاح طويل وعشوائي لجلسات العملاء |
| `ADMIN_JWT_SECRET` | مفتاح طويل وعشوائي مختلف لجلسة الإدارة |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة |

متغيرات Twilio اختيارية، ولا تمنع الطلب كزائر:

- `TWILIO_ACCOUNT_SID`
- `TWILIO_AUTH_TOKEN`
- `TWILIO_WHATSAPP_FROM`
- `TWILIO_CONTENT_SID`
- `TWILIO_SMS_FROM`

## الدفع الإلكتروني

الدفع عند الاستلام والتحويل البنكي يعملان كطرق تسجيل للطلب. ربط البطاقات أو Apple Pay يحتاج حسابًا ومفاتيح من بوابة دفع مناسبة، ثم إضافة مسار الدفع الآمن في الباك إند. خيار الدفع الإلكتروني معطل افتراضيًا حتى يتم ربط بوابة حقيقية.

## الصور التجريبية
تمت إضافة صور تجريبية قابلة للاستبدال داخل المجلد:

`assets/demo/`

وتشمل:
- بانر رئيسي للرئيسية/الفرنسي
- بانر لقسم النيش
- بانر عربي
- بطاقة "اطلب عطرك"
- 6 صور منتجات تجريبية

### آلية العمل
- إذا كان المنتج في قاعدة البيانات يحتوي على `image_url` فسيتم عرض صورته القادمة من الباك إند.
- إذا كان `image_url` فارغًا فسيتم عرض صورة تجريبية تلقائيًا من `assets/demo/`.
- يمكنك استبدال أو حذف الصور التجريبية لاحقًا، أو جعل كل الصور تأتي من الباك إند فقط.
